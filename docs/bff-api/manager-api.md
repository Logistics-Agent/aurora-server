## 2. Supervisory Endpoint Specifications

### `POST /api/v1/approvals/{id}/approve`
- **Purpose:** Authorizes a high-risk route recommendation generated by the AI Route Planning Agent, unblocking active dispatch.
- **Permission:** `route_planning:approve`
- **Scope:** Approval Ticket
- **Backend RPC:** `RoutePlanningService.ApproveRoute`
- **Request Body:**
  ```json
  {
    "comment": "Approved following hazardous materials route inspection."
  }
  ```
- **Response (`200 OK`):**
  ```json
  {
    "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "routeId": "4ba85f64-5717-4562-b3fc-2c963f66afa6",
    "status": "APPROVED",
    "reason": "Route approved by supervisor",
    "createdAt": "2026-09-04T12:00:00Z"
  }
  ```

---

### `POST /api/v1/mail/threads/{id}/reassign`
- **Purpose:** Reassigns thread ownership from one team member to another with mandatory business justification.
- **Permission:** `mail:thread:reassign`
- **Scope:** Thread
- **Backend RPC:** `MailSecurity.ReassignThread`
- **Request Body:**
  ```json
  {
    "targetUserId": "1fa85f64-5717-4562-b3fc-2c963f66afa6",
    "reason": "Rebalancing workload for priority Rotterdam container booking."
  }
  ```
- **Response (`200 OK`):**
  ```json
  {
    "success": true,
    "threadId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "primaryAssigneeUserId": "1fa85f64-5717-4562-b3fc-2c963f66afa6",
    "assignedAt": "2026-09-04T12:30:00Z",
    "status": "IN_PROGRESS"
  }
  ```

---

### `POST /api/v1/mail/threads/{id}/unassign`
- **Purpose:** Returns a previously claimed thread back to the unassigned team queue.
- **Permission:** `mail:thread:unassign`
- **Scope:** Thread
- **Backend RPC:** `MailSecurity.UnassignThread`
- **Request Body:**
  ```json
  {
    "reason": "Staff member on unplanned leave; released back to shared pool."
  }
  ```
- **Response (`200 OK`):**
  ```json
  {
    "success": true,
    "threadId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "status": "UNASSIGNED"
  }
  ```
