=====
Tình huống B: Developer muốn chạy và test code trực tiếp ở Local (không cần deploy lên Cloud)
====
Để dev / test nhanh tính năng mà không cần mỗi lần sửa code phải build Docker push lên AKS:

1. Chạy hạ tầng phụ trợ bằng Docker Compose ở Local:
	Chạy Redis, PostgreSQL ở local qua file docker-compose.yml.
2. Cấu hình biến môi trường (appsettings.Development.json hoặc .env.local):
	Database / Redis: Trỏ về localhost (localhost:5432, localhost:6379).
	Cognito / S3 / R2: Dùng các Client ID & Endpoint từ môi trường Demo đã tạo sẵn trên Cloud để xác thực người dùng thật.
3. Kết nối Local trực tiếp vào Kubernetes (Nâng cao - Dùng mirrord hoặc telepresence):
	Nếu bạn muốn service chạy dưới máy local nhưng có thể gọi trực tiếp sang các pod nội bộ khác (như OSRM, Internal APIs) trên AKS, chỉ cần dùng extension mirrord trên VS Code / JetBrains.
